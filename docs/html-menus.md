# K-CD HTML menus (2012)

`kcd-html-1` observes the static current-disc `scripts/cdindex.js` register and
its referenced HTML pages. No JavaScript, Flash or executable is run. It is a
separate adapter; it does not manufacture K.DTX sections.

The accepted template has individual software pages and grouped article/video
pages. Every index row must bind to exactly one page headline. All numbered
software pages and all grouped article/video headlines must be indexed; unknown
index syntax, controls, duplicate matches and disagreement stop processing.
Only known literal window.open/show controls are parsed as file observations.
Paths must remain inside the source. External URLs stay observations, not downloads.

Original index/page bytes, hashes and selectors accompany observations. HTML's
ISO-8859-1 label is decoded as Windows-1252 (browser semantics), including the
three en dashes observed on 16/2012. Text retains line breaks and entities are
decoded; UI download labels are excluded, original linked prose is preserved.
Source versions/licenses are observations, never installed-product identification.
Screenshots are taken from each entry's explicit image element, not inferred from
nearby programs. Articles/video courses get separate source posts, but their PDF,
SWF and executable payloads are not published by the image pipeline.

The historical article-search XML/Silverlight database is not the current CD
inventory. Membership/search/navigation pages are not additional software posts.
The declared coverage is the current index and matching menu pages, not complete
runtime or historical-article coverage.

For these images, 7-Zip autodetection opens an embedded Silverlight ZIP instead
of the ISO filesystem; forcing ISO also fails. macOS mounting succeeds but has
unreadable directory/file observations. `/usr/bin/tar -xf IMAGE -C NEW_DIRECTORY`
reads the ISO contents successfully. Supply that directory with `--image IMAGE`
to retain independent original-image identity. Do not treat the ZIP listing as a
complete CD, silently drop unreadable source files, or execute installers.

Real-media acceptance and all exceptions are recorded in the project intake
report for 5, 14, 16 and 18/2012. Source-readiness is distinct from product identity.
